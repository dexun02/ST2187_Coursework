# ST2187_Coursework – Tableau Dashboard & Report

This repository contains the final deliverables for a business analytics project focused on identifying and addressing profit inefficiencies in a logistics dataset. The project includes a written report and a Tableau storyboard that visualize and analyze key operational trends.

## Project Overview

The goal of this project was to uncover the root causes behind declining profitability and propose data-driven solutions. Using Tableau, I analyzed operational metrics such as shipping costs, delivery delays, and order volumes to derive actionable insights.

## Tools Used

- **Tableau** – for data visualization and interactive dashboards  
- **Excel / CSV** – as data source  
- **Microsoft Word** – for report presentation
